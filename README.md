🏥 MEDTECH
Hospital Resource Management System

MEDTECH is a hospital resource management system designed to help manage patients and hospital resources efficiently.

Features
👤 Patient registration
🏥 Hospital resource overview
👨‍⚕️ Doctor assignment
🛏️ Bed assignment
🫁 Ventilator assignment
📋 Patient records
🏥 Bed availability tracking
👨‍⚕️ Doctor availability tracking
⚕️ Patient condition and location management
🩸 Blood group information
🚨 Resource management for critical patients
Technologies Used
Python
Streamlit
Pandas
Object-Oriented Programming (OOP)
Git & GitHub

How to Run

Install the required libraries:

python -m pip install streamlit pandas

Run the application:

python -m streamlit run app.py

The application will open in your browser.
